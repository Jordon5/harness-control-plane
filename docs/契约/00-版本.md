# 契约版本规则

> 元契约。ADR-012：平台价值 = 契约稳定性。当前 `@hcp/contracts` **尚未实行**下列规则，M3 冻结 ContextPack 前应落地。

---

## 1. 包 semver（`@hcp/contracts`）

| 变更 | 版本 |
|---|---|
| 破坏：改 `CreateRunArgs` 必填形状、删 `EventType`、改 `Store` 方法签名 | **major** |
| 兼容：新增可选字段 / 可选方法 / 新 `EventType` | **minor** |
| 文档、注释、无行为影响 | **patch** |

adapter / core / cli 只依赖 contracts 的公开导出。

## 2. 事件向前兼容（ADR-003）

- `EventType` **只追加、不删、不改名**。
- 未知 type **降级为 `run.output`**，`raw` 保留原文（adapter-cli 已如此）。
- `raw` 不得丢。

## 3. YAML schema 版本

- 任务 YAML 增加顶层 **`schema: <int>`**（缺省 = 1）。
- 解析器按版本填默认；升 major 才允许不兼容默认值。
- 这是 D8「今天人写、将来 AI 写」的逃生口：改 schema 不靠默契。

## 4. 可选方法模式

新生命周期能力先做成 `HarnessAdapter` 的 **可选方法**（`collectUsage?`），旧 adapter 不实现仍能跑。变必填 = major。

## 5. Manifest 扩展

`HarnessManifest` 新字段（如 `injection`）必须 **optional**。旧 adapter 的 `manifest()` 不返回该字段时，core 把 `stageIntent` 写入 `prompt`，**不**拒绝写入型 Stage（见 02）。
