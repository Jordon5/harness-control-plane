# 已冻契约

> 源码：`packages/contracts/src/`。下列只写语义；字段表以 `.ts` 为准。

---

## 1. Harness 身份与配置 — `harness.ts`

- **`TransportKind`**：`cli` | `local-server` | `remote-service` → 决定基类，不是路由依据。
- **`Capability`**：已知四值 + `(string & {})` 自定义；路由按 **集合包含**（`requires ⊆ capabilities`）。
- **`ExecutionProfile`**：写入型 Stage 过滤 `supportsWorktree === true`。
- **`HarnessManifest`**：adapter 的 `manifest()` 返回；**尚未含注入通道**（见 [02-M3必冻.md](./02-M3必冻.md)）。
- **`HarnessConfig`**：实例化参数；`options` 为 adapter 私有袋（pi 的 provider/model 走这里，不进契约）。

## 2. 适配器生命周期 — `adapter.ts`

`HarnessAdapter`：探活 → `createRun` → `streamEvents` → `collectResult` / `collectUsage?` → `cleanup`。

- **事件归属（adapter-cli 约定）**：基类 emit `run.started` 与终结事件（completed/failed/cancelled）；子类 `parseLine` 只产中间事件。
- **`CreateRunArgs.prompt`**：M1 占位。M3 将 **并列** 可选 `context?: ContextPack`（见 02），不删除 `prompt`。
- **`collectUsage?`**：D6 出口；不支持的 adapter 可省略。累计用量由基类保留最近一次快照。

## 3. 事件与结果 — `event.ts` / `result.ts`

- 最小事件集见 architecture §4.4；无法归类 → `run.output` + 保留 `raw`。
- `UnifiedEvent.timestamp`：ISO 字符串（core 归一化）；harness 原文里的 epoch 留在 `raw`。
- `UnifiedResult.status` 是结局（`RunOutcome`），与运行中 `RunState` 分名不分家。

## 4. 任务 YAML 归一化 — `task.ts`

契约只描述**填好默认之后**的形态。YAML 用 snake_case；映射在 `core/schema`。

| YAML | TS | 默认（schema 填入） |
|---|---|---|
| `depends_on` | `dependsOn` | `[]` |
| `owned_paths` | `ownedPaths` | `[]` |
| `kind` | `kind` | `harness` |
| `mode` | `mode` | `read-only` |
| `retry.max` | `retry.max` | `0` |
| `timeout` | `timeout` | `null`（时长字符串，如 `"30m"`；转毫秒在执行层） |

校验（非类型能表达的）：`kind=harness` 必须有 `harness`；`kind=local-command` 必须有 `command`；stage id 唯一；`depends_on` 存在且无环。

## 5. 持久化 — `store.ts` + `records.ts` + `usage.ts`

- Store **同步**（node:sqlite / 内存均为同步驱动）。换异步驱动 = 改签名 = major。
- 无事件清理接口 = 全量保留（ADR-008）。
- **四根桩形状已在，运行时写入方是 Scheduler（M3）**：
  - D6 `usage` 表 / `appendUsage`
  - D7 `RunRecord.configRef`
  - D9 `ContextRecord` / `appendContext`（M1 只写不注）
  - events 全量
- `ContextKind`：`decision` | `convention` | `gotcha` | `note`。
- `T | null` 而非 `undefined`：落库往返一致。

## 6. 已知缺口（不在本文件补实现）

见 [02-M3必冻.md](./02-M3必冻.md)。已冻面里唯一「会挡 M3」的是 **`CreateRunArgs.prompt` 过窄** 与 **`HarnessManifest` 无 injection**。
